# 十枚目

番町皿屋敷をもとにした、見下ろし3Dの屋敷逃走劇（なすびのお庭）。

- `index.html` … 遊ぶページ（下の `src` から作った1枚のファイル。これだけで動く）
- `okiku/` … お菊さんのモデルと「捕まる場面」だけを確かめるページ
- `src/` … もとになるプログラム
  - `game.js` 屋敷での遊び（自分・お菊さんの動き・はじまりの映像・画面の表示）
  - `world.js` 毎回ちがう間取りを作る
  - `okiku.js` お菊さんのモデル（髪・顔・手）
  - `catch.js` 捕まる場面　`audio.js` 音と声　`post.js` 画面の仕上げ（粗いドット・ざらつき）
- `vendor/pixelfx/` … ドット絵の演出（人魂・鍵のきらめき）。MIT License

## 作りなおし方

```
npm install
npm run build
```
